# Memory: a Codex decision, recalled for Claude Code

1. In Codex, the user asks for the three-step plan and the first two steps
   (the same session as [codex-to-claude](../codex-to-claude/README.md)).
   Before it stops, Codex records why `hello.py` is written the way it is:
   `agent-autosave note --quiet --type decision "hello.py prints with print(), not logging, so a check can read its stdout"`.
2. The user runs `agent-autosave done`. The task gets a journal page, and
   Codex's note becomes a candidate.
3. The user runs `agent-autosave memory review` and accepts it. It lands in
   `MEMORY.md` under Decisions, credited to Codex, and the journal page
   links to it.
4. The next day a new Claude Code session starts with the project-memory
   block, and its first prompt, about the same file, is given the decision
   and the earlier task.

The recorded Codex session had no decision note and the user's `done` was
not recorded: `scripts/build-examples.py` adds both, with times between the
recorded ones. Everything else is the real recording; `replay.py` derives
every file below from the ledger and `prompt.txt`.
