# Claude Code to Codex

1. In Claude Code, the user asks for a three-step plan (write `hello.py`,
   run it, add a failing check) and step 1 only. Claude writes `hello.py`
   and keeps the plan as a checklist in its reply.
2. Next prompt: run `python3 hello.py` (exit 0), then
   `python3 -c "raise SystemExit(7)"` (exit 7), and stop.
3. The user runs `/compact`, then `/exit`. The save is now **paused**.
4. Codex starts in the same folder. Its SessionStart hook injects the save,
   and the save records the handoff (`claude-code` to `codex`).

[`.autosave/SAVE.md`](.autosave/SAVE.md) is the save after the Codex
session, which is what the next agent would get. It lists
the goal, the plan (2 of 3 done), the failing command, `hello.py`, and the
next action: make the failing command pass.
