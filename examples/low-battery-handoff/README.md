# Low battery: Codex hands off before its limit

1. In Codex, the user asks for the three-step plan. Codex records it with
   `agent-autosave plan set`, writes `hello.py` and marks step 1 done.
2. At that Stop, Codex's session rollout reports 91% of its 5-hour limit
   used. That is past `handoff.warn_at_percent` (85).
3. On the next prompt the UserPromptSubmit hook adds one ask, in
   [`ask.txt`](ask.txt): record a handoff note. Codex runs
   `agent-autosave note "..." --type handoff`, then carries on with the
   prompt and stops. It is asked once per crossing; once a handoff note is
   recorded it is not asked again.
4. Claude Code starts in the same folder. Its block carries the handoff
   note and Codex's usage, and the save records the handoff.

The recorded Codex session had neither the 91% reading nor the note:
`scripts/build-examples.py` adds a `token_count` row in the shape codex-rs
writes to the rollout, and runs the note command where the agent would.
Everything else is the real recording.
