# Codex to Claude Code

1. In Codex, the user asks for the same three-step plan. Codex records it
   with `agent-autosave plan set`, writes `hello.py` with `apply_patch`, and
   marks step 1 done with `agent-autosave plan done 1`.
2. Next prompt: run `python3 hello.py` (exit 0), mark step 2 done, then run
   `python3 -c "raise SystemExit(7)"` (exit 7), and stop.
3. The user runs `/compact`, then `/quit`. The save is now **paused**.
4. Claude Code starts in the same folder. Its SessionStart hook injects the
   save, and the save records the handoff (`codex` to `claude-code`).

[`.autosave/SAVE.md`](.autosave/SAVE.md) shows the plan as Codex recorded
it, the exit-7 command as the failure, `hello.py` as edited, and the next
action.
