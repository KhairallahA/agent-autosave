# agent-autosave v0.1.0

**Who it's for:** Anyone deciding whether to try the first release, and the maintainer writing its announcement.

The first release. Your coding agent autosaves to `.autosave/` in your
repository as it works. When it stops (a usage limit, a crash, a closed
terminal), the next session, in the same agent or another one, starts from
the save. What the agents learn about the repo becomes project memory that
you review.

## Install

```sh
brew install KhairallahA/agent-autosave/agent-autosave
# or
pipx install agent-autosave
# or
curl -fsSL https://raw.githubusercontent.com/KhairallahA/agent-autosave/main/install.sh | sh
```

Python 3.9 or newer; no other dependencies. macOS and Linux are supported;
Windows (`install.ps1`) is experimental.

## What's in it

- **It saves.** Hooks for Claude Code, Codex, Cursor, Gemini CLI,
  Antigravity and GitHub Copilot CLI, and a plugin for OpenCode, record the
  goal, the plan, commands and exit codes, failures, touched files and
  usage into an event ledger. Any other `AGENTS.md` agent gets an
  instruction block. A pure compiler turns the ledger into `save.json` and
  `SAVE.md` without a model: the same events give the same bytes.
- **It hands off.** `agent-autosave go claude-code codex` runs Claude Code
  and, when it hits its usage limit, asks once and starts Codex with the
  save. `resume <agent>` and `resume --next` do it by hand. At 85% of its
  window the agent is asked to write a handoff note first.
- **You can see it.** Claude Code's status line shows the save and the
  usage; `watch` is a live screen; `status`, `show` and `history` are styled
  for a terminal and JSON when piped.
- **It remembers.** Notes become candidates you accept with
  `memory review`; `MEMORY.md` (in the repo or an Obsidian vault) is given
  to later sessions and recalled on matching prompts. Each finished task
  gets a journal page. It works alongside agentic-stack.
- **Agents can use it as tools.** `agent-autosave mcp` is a local MCP
  server for the save, the plan, notes and memory.
- **Teams.** `share on` commits project memory and the journal;
  `handoff export` and `import` pass one task to a teammate.
- **An open format.** The save, ledger and memory files are specified as
  version 1, with JSON Schemas and conformance tests.
- **Setup you can undo.** The `init` wizard shows every change before
  writing it, `doctor` prints the fix for each problem, and `remove`
  restores every file byte for byte.

Hooks always exit 0 and stay under 300 ms; nothing leaves your machine.

## Known limits

- Claude Code, Codex and Antigravity are built from recorded sessions.
  Cursor, Gemini CLI, Copilot CLI and OpenCode follow their documentation
  and have not been recorded yet; each adapter page lists what is
  unconfirmed. Antigravity reports no exit codes, so its commands' results
  are shown as unknown.
- The handoff benchmark has no published numbers yet: they come from real
  runs only.
- Windows is experimental: the test suite still hangs on GitHub's Windows
  runners.
