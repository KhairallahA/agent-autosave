# homebrew-agent-autosave

The Homebrew tap for [agent-autosave](https://github.com/KhairallahA/agent-autosave).

```sh
brew install KhairallahA/agent-autosave/agent-autosave
```

`Formula/agent-autosave.rb` is a copy of the formula in the main
repository, with `url` and `sha256` set by `scripts/update-formula.py`
for each release. Don't edit it here; change it in the main repository and
copy it over (see `docs/releasing.md` there).
